# Security Policy

## Scope

Python TLS-certificate status checker that connects to user-supplied endpoints.

Reports about unsafe input, unintended credential exposure, dependency security, or misleading certificate results are in scope. Only test endpoints you own or are authorized to inspect.

## Private and responsible reporting

Do not publish credentials, tokens, private information, sensitive proof-of-concept details, or personal data in issues, pull requests, discussions, or Actions logs.

If GitHub's private **Report a vulnerability** option is available under this repository's Security tab, use that route. If it is unavailable, request a private reporting channel in a public issue **without sharing sensitive details**. Do not assume that a public issue is confidential.

Reports should identify the affected file/version, observed impact, and minimal sanitized reproduction information. There is no stated service-level agreement or guarantee that a report will be fixed. Do not perform unauthorized testing.

This policy does not declare the repository or any associated website free from vulnerabilities. Existing ownership and licensing terms remain unchanged.
